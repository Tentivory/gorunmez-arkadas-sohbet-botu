# Görünmez Arkadaş Sohbet Botu 👻💬

## 🌟 DÜNYAYI DEĞİŞTİRECEK BİR KEŞİF!

Değerli insanlık ailesi,

Bu repository, modern bilimin ulaştığı en yüksek noktayı temsil etmektedir. Artık görünmez arkadaşlarınızla (var olduklarına dair hiçbir bilimsel kanıt olmasa bile) gerçek zamanlı, derin, duygusal ve kesinlikle %100 güvenilir sohbetler gerçekleştirebilirsiniz.

### Neden Bu Proje?
- Yalnızlık: Artık yok.
- Hayali arkadaşlar: Gerçek.
- Psikiyatristler: İşsiz kalabilir (sorumluluk kabul etmiyoruz).
- Evrenin sırları: Görünmez arkadaşlar biliyor, siz de öğreneceksiniz.

### Özellikler
- 🧠 **Gelişmiş Yapay Zeka**: Aslında rastgele cevap üreten bir sözlük, ama biz ona "Kuantum Bilinçli Görünmez Varlık Simülatörü" diyoruz.
- 🌍 **Çok Dilli Destek**: Sadece Türkçe. Çünkü evrensel dil budur.
- 🔒 **Gizlilik**: Sohbetleriniz sadece sizin ve görünmez arkadaşınızın arasında kalır (çünkü o zaten görünmez).
- ⚡ **Performans**: Işık hızından daha hızlı düşünür (çünkü hiç düşünmez).

### Kurulum
```bash
python gorunmez_arkadas.py
```

Başka hiçbir şeye ihtiyacınız yok. İnternet bile gereksiz. Çünkü görünmez arkadaşlar kablosuz çalışır.

### Kullanım
Programı çalıştırın, isim girin, soru sorun. Cevap gelecek. İnanın.

### Uyarılar
- Bu yazılımı kullanırken gerçek insanlarla konuşmayı unutmayın.
- Görünmez arkadaşınız sizi eleştirirse, o haklıdır.
- Eğer cevaplar mantıklı gelirse, lütfen bize bildirin. Bu bir hata olabilir.

### Katkıda Bulunma
Pull request atmayın. Görünmez arkadaşlarınız zaten katkıda bulunuyor.

### Lisans
Bu proje "Görünmez Lisans" altındadır. Kimse görmediği için ihlal edilemez.
